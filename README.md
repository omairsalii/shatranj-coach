# شطرنج المدرب ♞

تطبيق شطرنج عربي لأندرويد (APK) ونسخة ويب، مع مدرب ذكي يشرح النقلات.

## المزايا

- **التدريب مع المدرب:** بعد كل نقلة يقيّمها المدرب (أفضل نقلة / ممتازة / جيدة / غير دقيقة / خطأ / خطأ فادح)، ويشرح بالعربية لماذا، وما النقلة التي كان يجب أن تلعبها ولماذا (شوكة، تثبيت، سيخ، هجوم مكشوف، كسب مادة، تطوير، سيطرة على المركز…)، ويحذرك من تهديدات الخصم، مع إمكانية التراجع وتجربة نقلة أفضل.
- **🧭 ما الخطة؟** نصائح استراتيجية للوضع الحالي، والتعرف على اسم الافتتاح وفكرته.
- **العب ضد الكمبيوتر:** محرك Stockfish بعشرة مستويات من المبتدئ إلى أقصى قوة.
- **العب مع صديق برابط:** أنشئ غرفة، شارك الرابط (واتساب وغيره)، ويبدأ اللعب عند فتحه. الاتصال مباشر بين الجهازين (WebRTC).
- **التحكم بالتلميحات:** في المباراة مع صديق تختار: تفعيل التلميحات لك، والسماح أو المنع لخصمك، ويمكن تغييرها أثناء اللعب. التلميح يظهر فقط على جهاز صاحبه.
- **مراجعة المباراة:** نسبة الدقة، وعدد الأخطاء، وشرح كل خطأ على اللوحة.
- **الدروس:** الأساسيات، الاستراتيجية، التكتيكات مع ألغاز تفاعلية (منها المات العربي)، والافتتاحات مع عارض للنقلات.
- **ساعة الشطرنج:** اختر وقت كل لاعب (1، 3، 5، 10، 15، 30 دقيقة) مع إضافة ثوانٍ بعد كل نقلة، في كل الأوضاع بما فيها اللعب أونلاين؛ من ينتهي وقته يخسر.
- لاعبان على نفس الجهاز.

## التحميل

كل تحديث على الفرع `main` يبني ملف APK تلقائياً عبر GitHub Actions وينشره في صفحة الإصدارات:
`https://github.com/omairsalii/shatranj-coach/releases/latest/download/shatranj-coach.apk`

عند التثبيت قد يطلب أندرويد السماح بـ "التثبيت من مصادر غير معروفة".

## روابط الدعوة

- رابط الدعوة بالشكل `https://omairsalii.github.io/shatranj-coach/?join=ABC123`.
- إذا كان التطبيق مثبتاً يمكن للصديق فتح التطبيق ← "انضم بدعوة" ولصق الرابط أو الرمز.
- لكي يعمل الرابط في المتصفح لمن لا يملك التطبيق: فعّل GitHub Pages من
  **Settings → Pages → Source: GitHub Actions**، وستُنشر نسخة الويب تلقائياً مع كل تحديث على `main`.
- يستخدم الربط بين اللاعبين خادم PeerJS العام المجاني (`0.peerjs.com`) لتبادل بيانات الاتصال فقط؛ النقلات تنتقل مباشرة بين الجهازين.

## البنية

```
./
  web/        واجهة التطبيق (HTML/CSS/JS) — تعمل كما هي في المتصفح
    js/app.js       الشاشات وأوضاع اللعب
    js/coach.js     المدرب: تقييم النقلات وشرح التكتيكات والخطط والافتتاحات
    js/engine.js    غلاف محرك Stockfish (Web Worker)
    js/online.js    اللعب أونلاين (PeerJS)
    js/lessons.js   الدروس والألغاز
  android/    مشروع أندرويد (WebView) يغلّف مجلد web
```

للتجربة محلياً: `cd ./web && python3 -m http.server` ثم افتح `http://localhost:8000`.
